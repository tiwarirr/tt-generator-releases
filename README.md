# TT Generator — downloads

Installers for **TT Generator**, a timetable app for CBSE schools.

Get the latest version from **[Releases](https://github.com/tiwarirr/tt-generator-releases/releases/latest)**:

- **Mac** (Apple chip): `TT-Generator-<version>-arm64.dmg`. Open it and drag TT Generator onto Applications.
- **Windows** (64-bit): `TT-Generator-Setup-<version>.exe`. Run it; no administrator password is needed.

The app checks this page for new versions by itself.

The installers are not yet signed. The first time you open the app, the computer asks you to confirm:

- **Mac:** System Settings → Privacy & Security → **Open Anyway**.
- **Windows:** "Windows protected your PC" → **More info** → **Run anyway**.

This repository holds only the installers. Your school's data stays on your own computer and is never uploaded here.
